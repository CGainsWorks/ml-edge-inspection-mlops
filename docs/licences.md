# Licences and data provenance

## This repository

Apache-2.0. See [`LICENSE`](../LICENSE).

## The data the published numbers came from

Every number in this repository was produced from **synthetic data generated by
this repository**. There is no third-party data in the results, in the models,
or in the Git history.

| | |
|---|---|
| Name | `edgeinspect-synth` |
| Generator | [`src/edgeinspect/data/synth.py`](../src/edgeinspect/data/synth.py) |
| Licence | Apache-2.0, same as the code that produces it |
| Commercial use | yes |
| Redistributable | yes, though it is regenerated rather than shipped |
| Used for published numbers | **yes** |

The dataset is not committed. `scripts/make_dataset.py` rebuilds it byte for
byte from the seeds in `configs/data.yaml`, and `--verify` regenerates a sample
and compares the PNG bytes, so the data behind a result is reproducible without
storing it.

## The real datasets this project supports but does not ship

Both are supported by [`src/edgeinspect/data/mvtec.py`](../src/edgeinspect/data/mvtec.py)
against a copy you download yourself. Neither may be redistributed, and one may
not be used commercially, so neither is downloaded automatically and neither
contributed to any published number.

### MVTec AD

| | |
|---|---|
| Licence | **CC BY-NC-SA 4.0** |
| Commercial use | **no** |
| Redistributable | **no** (and share-alike would infect a derivative dataset) |
| Source | <https://www.mvtec.com/company/research/datasets/mvtec-ad> |
| Used here | no |

The share-alike clause is the sharper of the two problems. A dataset *derived*
from MVTec AD inherits CC BY-NC-SA, so committing converted frames into an
Apache-2.0 repository would be a licence violation even if the non-commercial
clause were acceptable.

### DAGM 2007

| | |
|---|---|
| Licence | Released for research use by the DAGM symposium organisers |
| Commercial use | **no** |
| Redistributable | **no** — no redistribution grant was given |
| Source | <https://hci.iwr.uni-heidelberg.de/content/weakly-supervised-learning-industrial-optical-inspection> |
| Used here | no |

### How the boundary is enforced

`scripts/make_dataset.py --source mvtec` refuses to run without
`--i-accept-dataset-licence`, and the refusal prints the licence and its
consequences. A required flag rather than a config default, because a build that
silently ingests CC BY-NC-SA data into an Apache-2.0 project is a licence
incident waiting to be discovered by somebody else.

`.gitignore` excludes `data/` entirely, so converted frames cannot be committed
by accident.

## Dependencies

Every runtime and training dependency is permissively licensed. Nothing here is
copyleft, and nothing forces a licence change on a downstream user.

| Package | Licence |
|---|---|
| numpy | BSD-3-Clause |
| scipy | BSD-3-Clause |
| pyyaml | MIT |
| pillow | MIT-CMU |
| onnx | Apache-2.0 |
| onnxruntime | MIT |
| mlflow | Apache-2.0 |
| torch, torchvision | BSD-3-Clause |
| pytest | MIT |
| flake8 | MIT |

Deliberately absent: **Ultralytics** (AGPL-3.0). A detector built on it would
make the deployed image AGPL, which for an edge product shipped to a customer's
factory is a licence question nobody wants to answer at integration time. The
detector here is written from scratch in about a hundred lines of PyTorch, which
is cheaper than that conversation.

The Jetson dependencies in `requirements-jetson.txt` — TensorRT, cuda-python,
onnxruntime-gpu — come from NVIDIA under their own terms, which are more
restrictive than the above. They are never installed here and appear only in the
image that was never built; see [`jetson.md`](jetson.md).

## Model provenance

There is no pretrained model, no downloaded checkpoint and no foundation model.
`DefectNet` is randomly initialised and trained from scratch on the generated
dataset, so there is no upstream licence, no upstream training data and no
question about what the weights encode.
